# Onboard H&S Dashboard — managed Windows updates (V4.8)

The application includes the groundwork for a user-approved update check using electron-updater. Updates are **disabled by default**. The Windows installer generated by the existing GitHub workflow is a build artifact only; it is **not** a hosted update feed.

## IT deployment checklist

1. Choose an HTTPS update distribution endpoint accessible to authorised PCs, with access restrictions suitable for a private work application. Do not embed GitHub personal access tokens or other reusable credentials in the app.
2. Arrange Windows code signing and restrict publication of installers to an approved release process. Verify certificates/publisher before deployment.
3. Configure electron-builder to publish Windows NSIS installers, update metadata (latest.yml), and any required blockmaps to that endpoint. Upload artifacts through a secured CI job with restricted secrets and approval controls; do not expose private releases to the public.
4. Set update-config.json to {"enabled":true,"feedUrl":"https://IT-APPROVED-HOST/path/"} **only after** the secure feed and release process have been tested. Rebuild/install one bootstrap version with this configuration.
5. Test a signed update from one version to a higher version on a non-production Windows PC. Verify both download and install, backup/restore, records.json persistence, all registers, attachments and sign-off records.
6. Obtain workplace IT approval before rollout. Keep the updater opt-in; users choose whether to download and when to restart/install.

## Current behaviour

- No auto-downloads or automatic installation occur without an approved, configured feed.
- The user data file remains stored under Electron's Windows userData directory, separate from installed application binaries. Exports are still recommended before each version change.
- GitHub Actions builds on source changes, but those builds do not currently distribute updates to installed applications.
- There is no login or web hosting of H&S records in this change.
